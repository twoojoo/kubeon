Features

Kubeon draws the k9s engine in a native desktop UI: live tables for every resource and CRD, describe and YAML in a drawer, logs and shells in a dock, and the views below. Everything works from the keyboard, k9s style, and with the mouse.

Also in Kubeon

  • Cluster overview: nodes, pods by status, deployment health, CPU and memory requests (and usage with metrics-server), warning events.
  • Secrets decoded in a tab, with per-key reveal and copy, and download as a .env file.
  • Node cordon, uncordon and drain; scale, rollout restart and delete, also on a multiple selection.
  • Tabs, bookmarks of resource, namespace and filter, dark and light themes, interface zoom.
  • Health notifications (CrashLoop, image pull errors, OOM, node NotReady, degraded deployments) on the desktop and in the app.
